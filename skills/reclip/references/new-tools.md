# Updated tool workflows

Every product tool is available through the generic quote/submit/status flow. Discover its live schema and catalog; the bundled catalog records the corresponding input fields and limits.

Find Clips by Prompt (`clip_discovery`) takes `prompt`, `duration` (up to 7200 seconds), `max_clip_seconds` (30, 60 or 90) and ordered, non-overlapping `cues` containing `start`, `end`, `text`. Transcribe a source first when cues are unavailable; reuse `outputs[].transcript_cues` from the completed transcription job. It costs one credit per started ten minutes, minimum one. Successful jobs return timestamped recommendations under `result.clips`; these are selections for review. Use the selected range in a subsequent trimming/clipping job when an exported video is requested. Cue JSON is bounded to 6000 cues, 200000 text characters and a 1.5 MiB request body.

AI B-Roll (`ai_broll`) takes exactly one of `asset_id` or a supported `source_url`, plus `options` with an end time. It supports image, video and stock modes, caption selection, time range, shot count and visual style. Quote the complete job through the existing approved server tariff shared with the browser. API and MCP access use that same approval; no separate pricing approval is needed. The server normalizes the shot count to the selected range. If the server returns `broll_pricing_unavailable`, report that the current tariff is unavailable; do not assume approval was never granted or substitute the browser display estimate.

After completion, use `broll JOB_ID` to inspect the current composition. `edit-broll JOB_ID edits.json` saves an explicit revision with bounded shot timing and crop position. Preserve original shot identity, media and provenance. `quote-broll-shot JOB_ID regeneration.json` quotes a replacement; `regenerate-broll-shot JOB_ID regeneration.json --maximum-credits N --state STATE` submits it with durable replay protection. `export-broll JOB_ID --revision R --state STATE` creates a free export of the selected composition revision. Poll each admitted job. The REST paths are `/broll/{id}`, `/broll/{id}/regenerate-quote`, `/broll/{id}/regenerate`, and `/broll/{id}/exports`.

Gemini Watermark Remover and Gemini Watermark Bulk Remover take `input_asset_ids` containing exactly one or 1–50 unique ready owned image assets. Supported files are JPEG, PNG and WebP, up to 10 MiB each. Submit with `maximum_credits: 0`; there is no credit charge. The API runs the same watermark library on the worker and returns individual PNG assets. Inspect `result.images`: only `applied` means the library applied removal; `needs_review` and `unsupported_watermark_style` require an honest report and review. Bulk results preserve each source asset ID. Download individual images; package them locally if a ZIP is requested.

Video Upscaler (`video_upscaler`) and AI Video Editor (`ai_video_editor`) use the latest source-duration, model, range, resolution and output constraints in their tool schema and catalog. Upload and confirm a compatible owned video, quote the exact settings, then submit. Video generation and ad generation model choices, image generation choices, captions and clipper presets, voiceover prices and dubbing languages/models are likewise obtained from their current live catalogs.
